SELECT *

FROM Orders

WHERE YEAR(CreatedDate) = 2026;  query này có nên viết ko vì sao....


==================================================
TỐI ƯU SQL: KHÔNG DÙNG HÀM TRÊN CỘT ĐƯỢC ĐÁNH INDEX
==================================================

1. VẤN ĐỀ VỚI QUERY: WHERE YEAR(CreatedDate) = 2026
- Bị vô hiệu hóa Index (Non-SARGable Query).
- Database bắt buộc phải làm Table Scan / Index Scan (duyệt 100% dòng trong bảng) 
  để tính hàm YEAR() cho từng dòng -> RẤT CHẬM VÀ TỐN CPU.

--------------------------------------------------

2. CÁCH KHẮC PHỤC: Chuyển thành tìm kiếm theo khoảng (Range Query)

   SELECT * 
   FROM Orders 
   WHERE CreatedDate >= '2026-01-01' AND CreatedDate < '2027-01-01';

- Giúp Database thực hiện INDEX SEEK (tìm trực tiếp trên cây Index B-Tree).
- Tốc độ truy vấn nhanh gấp hàng trăm lần trên bảng dữ liệu lớn.

--------------------------------------------------

3. QUY TẮC VÀNG TỐI ƯU SQL:
- KHÔNG DÙNG HÀM bọc xung quanh TÊN CỘT ở MỆNH ĐỀ WHERE.
- Lỗi tương tự hay gặp:
  + WHERE UPPER(UserName) = 'ADMIN'  -> Sửa thành: WHERE UserName = 'admin' (nếu DB CI)
  + WHERE SUBSTRING(Code, 1, 3) = 'ABC' -> Sửa thành: WHERE Code LIKE 'ABC%'
