==================================================
BẢN CHẤT CỐT LÕI CỦA OUT VÀ REF KEYWORD (C#)
==================================================

1. BẢN CHẤT BỘ NHỚ (MEMORY):
- Cả 'ref' và 'out' đều biến tham số thành CON TRỎ trỏ trực tiếp 
  đến Ô NHỚ GỐC của biến ở môi trường bên ngoài (Không tạo bản sao / Copy).

--------------------------------------------------

2. TÁC DỤNG LÊN VALUE TYPE VS REFERENCE TYPE:

A. VỚI VALUE TYPE (int, struct...):
- Giúp hàm sửa đổi trực tiếp giá trị nằm ở ô nhớ Stack của biến gốc.

B. VỚI REFERENCE TYPE (class, object...):
- Truyền thường (không ref/out): Chỉ sửa được THUỘC TÍNH bên trong Object. 
  Nếu 'new' Object mới trong hàm -> Biến bên ngoài KHÔNG thay đổi.
- Truyền có ref/out: Truyền chính "Con trỏ gốc". 
  Nếu 'new' Object mới hoặc gán 'null' trong hàm -> Biến bên ngoài SẼ TRỎ SANG OBJECT MỚI LUÔN.

--------------------------------------------------

3. KHI NÀO DÙNG CÁI NÀO? (BEST PRACTICES)

A. DÙNG 'REF' KHI:
- Cần ĐỌC giá trị cũ và CẬP NHẬT lại chính biến đó.
- Ví dụ 1: Hàm hoán đổi Swap(ref a, ref b).
- Ví dụ 2: Hàm ReloadObject(ref Config config) cần 'new' lại đối tượng nếu bị lỗi.

B. DÙNG 'OUT' KHI:
- Không quan tâm giá trị cũ, chỉ muốn LẤY DỮ LIỆU MỚI TỪ TRONG HÀM RA.
- Ví dụ 1: Các hàm TryParse -> int.TryParse("123", out int num).
- Ví dụ 2: Hàm trả về nhiều giá trị cùng lúc (Factory pattern / Out object).
==================================================



==================================================
BẢN CHẤT TRUYỀN THAM SỐ TRONG C#
==================================================

1. BÌNH THƯỜNG (KHÔNG REF/OUT) = TRUYỀN BẢN SAO (Pass-by-value):
- C# luôn đẻ ra một BẢN SAO (Copy) để đưa vào hàm.
- Với Value Type: Copy toàn bộ giá trị sang ô nhớ mới -> Sửa trong hàm KHÔNG đổi biến ngoài.
- Với Reference Type: Copy "con trỏ" sang con trỏ mới -> Nếu 'new' Object mới trong hàm, 
  con trỏ ngoài VẪN TRỎ VỀ OBJECT CŨ.

--------------------------------------------------

2. KHI DÙNG REF / OUT = TRUYỀN ĐỊA CHỈ Ô NHỚ (Pass-by-reference):
- C# KHÔNG tạo bản sao. Nó đưa chính ĐỊA CHỈ VẬT LÝ (Memory Address) của biến ngoài vào hàm.
- Mọi thao tác trong hàm tác động trực tiếp lên đúng ô nhớ gốc đó.
- Với Value Type: Sửa trực tiếp giá trị của biến ngoài.
- Với Reference Type: Đưa địa chỉ của "con trỏ gốc" vào -> Nếu 'new' Object mới trong hàm, 
  con trỏ ngoài SẼ TRỎ SANG OBJECT MỚI LUÔN.
==================================================



==================================================
Ý NGHĨA CỦA CON TRỎ (POINTER / REFERENCE)
==================================================

1. ĐỊNH NGHĨA DỄ HIỂU:
- Biến thường: Lưu GIÁ TRỊ thực sự của dữ liệu (ví dụ: lưu số 5, lưu chữ "ABC").
- Con trỏ: Lưu ĐỊA CHỈ Ô NHỚ (số nhà) nơi dữ liệu đó đang đứng.

--------------------------------------------------

2. VÍ DỤ ẨN DỤ:
- Biến thường = Ngôi nhà (chứa đồ đạc bên trong).
- Con trỏ = Mảnh giấy ghi "Số nhà" (chỉ đường tới ngôi nhà đó).

--------------------------------------------------

3. TẠI SAO CẦN CON TRỎ?
- Tối ưu bộ nhớ: Truyền dữ liệu lớn (ảnh, danh sách) vào hàm chỉ tốn 8 Byte 
  để truyền "Địa chỉ", không cần Copy toàn bộ dữ liệu -> Siêu nhanh.
- Chia sẻ dữ liệu: Nhiều con trỏ có thể cùng trỏ về 1 ô nhớ, 
  giúp các phần khác nhau của chương trình cùng thao tác trên 1 dữ liệu chung.
